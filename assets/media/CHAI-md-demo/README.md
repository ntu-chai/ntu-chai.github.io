# CHAI.md Vision Blueprint

An interactive digital-organism chart for the CHAI.md humanities AI symbiotic
evolution manifesto. The local page visualizes three organ layers:

- Cognitive & Linguistic Core
- Symbiotic Noosphere Loop
- Autonomous Governance Membrane

The SVG specimen breathes, the consciousness signal responds to stimulation,
organ selection updates the bilingual monitor, and vital signs drift over time.

## Run

```bash
python3 app.py
```

Open:

```text
http://127.0.0.1:8000
```

The lightweight Python server still exposes the original deterministic
SutraLens API endpoints for future demo reuse.
